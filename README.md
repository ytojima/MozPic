# MozPic — あそべるモザイクメーカー

画像をえらぶだけで、ハニカム・ステンドグラス・ブロック・アイコンなど 15 種類のモザイク画に。ガチャ、アニメーション、動画書き出しで遊べます。

## 🔒 画像はサーバに送信・保存されません

**MozPic はサーバに何も保存しません。画像も設定も、端末の外には一切送られません。**

- 画像の読み込み・モザイク処理・動画の書き出しは、すべてブラウザの中で行います。サーバ側のプログラムはありません（静的ファイルのみ）。
- 本番ビルドには Content Security Policy を設定しており、`connect-src 'none'` などで **ブラウザ自身が外部への通信（fetch / XHR / WebSocket / Beacon / フォーム送信 / 外部画像）をブロック**します。設定は `vite.config.js` にあります。
- フォントも含めてすべて同じサイトから配信しており、Google Fonts などの外部サービスにはアクセスしません。
- アクセス解析・広告・Cookie は使っていません。
- お気に入りとテーマの設定だけは、そのブラウザの `localStorage` に保存されます（外部送信なし）。お気に入りはアプリ内から削除できます。
- ページの配信元（GitHub Pages）には、一般的なアクセスログが残る場合があります。画像の中身が送られることはありません。

## 開発

```sh
npm install
npm run dev     # 開発サーバ
npm run build   # 本番ビルド（dist/）
```

## デプロイ

`main` ブランチへの push で GitHub Actions が GitHub Pages に公開します（`.github/workflows/deploy.yml`）。
公開パスと OGP 用の絶対 URL はワークフローが自動で設定します。
